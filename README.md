## 🚀 What I Build

웹 서비스의 화면과 서버, 데이터 흐름을 함께 설계하고 구현합니다. 덕후를 위한 커뮤니티 [Duckmu](https://duckmu.com/), 브라우저에서 바로 쓰는 도구 모음 [BeomTools](https://parkbeommin.github.io/tools/), 프론트엔드 유틸리티 패키지 [beomtil](https://www.npmjs.com/package/beomtil)처럼 필요하다고 느낀 것을 직접 만들어 운영합니다.

요즘은 **AI 에이전트 하네스**를 설계합니다. 역할은 에이전트 정의로, 도메인 지식은 스킬로, 순서·병렬·검증 게이트는 Workflow 스크립트로 나눠 담는 방식입니다. 판단은 모델에 맡기고 흐름은 코드가 강제하게 두면, 한 번 설계한 작업을 다음부터는 입력만 바꿔 반복할 수 있습니다. 하네스를 만드는 하네스 [mabu](https://github.com/ParkBeomMin/mabu), 그것으로 설계해 세미나 녹음 하나에서 요약·카드뉴스·인포그래픽·발표덱을 뽑는 [seminar-studio](https://github.com/ParkBeomMin/seminar-studio)가 그 결과물입니다.
