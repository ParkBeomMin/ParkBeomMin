### 반갑습니다! 👋

웹 서비스를 만드는 개발자 박범민입니다. Vue와 Node.js, Spring Boot로 화면과 서버, 데이터 흐름을 함께 설계하고 구현합니다. 필요하다고 느낀 것은 직접 만들어 내보내는 편이라, 덕후를 위한 커뮤니티 [Duckmu](https://duckmu.com/), 브라우저에서 바로 쓰는 도구 모음 [BeomTools](https://parkbeommin.github.io/tools/), 프론트엔드 유틸리티 패키지 [beomtil](https://www.npmjs.com/package/beomtil) 같은 것들을 만들어 운영하고 있습니다.

요즘은 AI 에이전트 하네스를 설계합니다. 역할은 에이전트 정의로, 도메인 지식은 스킬로, 순서와 병렬과 검증 게이트는 Workflow 스크립트로 나눠 담는 방식입니다. 판단은 모델에 맡기고 흐름은 코드가 강제하게 두면, 한 번 설계한 작업을 다음부터는 입력만 던져서 반복할 수 있습니다. 하네스를 만드는 하네스인 [mabu](https://github.com/ParkBeomMin/mabu), 그것으로 설계해 세미나 녹음 하나에서 요약과 카드뉴스와 발표덱을 뽑는 [seminar-studio](https://github.com/ParkBeomMin/seminar-studio)가 그렇게 나온 결과물입니다.

만드는 과정에서 배운 것은 [dev.duckmu.com](https://dev.duckmu.com/)에 남깁니다.
